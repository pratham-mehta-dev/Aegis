2. Cold-Boot Startup Sequence

Always boot the systems in this order so network APIs are ready before dependent daemons initialize:

Step 1: Windows Host (Backend & Web UI)

1. Open PowerShell in your project folder and start the server:

cd D:\Projects\aegis-project\aegis
npm start

2. Open your browser to http://localhost:4001 and verify the SOC Overview displays BLOCKED SOURCES: 0.

Step 2: Aegis Sensor VM (Gateway & Security Daemons)

1. Test API connectivity to the host backend:

curl -s -H "Authorization: Bearer 3a70ea1b032a8828b401b7f1557df41d717fd1f874dc9fc7f99768b0df399897b047b438eade1b96442ab64b7042dffb" \
  http://192.168.56.1:4001/api/ids/suricata/blocks

Expected Output: {"blocked":[]}

2. Verify daemon states:

sudo systemctl status suricata suricata-forwarder aegis-block-sync --no-pager

3. Ensure the direct input drop rule is active in nftables:

sudo nft add chain inet aegis_filter input '{ type filter hook input priority filter; policy accept; }' 2>/dev/null || true
sudo nft add rule inet aegis_filter input iifname "enp0s8" ip saddr @blocked_clients drop 2>/dev/null || true

Step 3: Aegis Client VM (Attacker / Target)

Boot the Client VM and confirm baseline reachability to the sensor gateway:

ping -c 2 -W 1 10.77.0.1

Expected Output: 0% packet loss (Client has normal connectivity).

3. End-to-End Live Demonstration Workflow

Phase 1: Clean Baseline State

Show the SOC Dashboard at http://localhost:4001 with 0 blocked hosts, and show a successful 2-packet ping from the Client VM.

Phase 2: Trigger Attack Bursts

From Terminal 2 (Aegis Client VM), run the automated port scan burst:

sudo true
for i in {1..3}; do
  echo "--- Burst $i ---"
  sudo nmap -sS -Pn -T4 -p 1-30 10.77.0.1 > /dev/null
  sleep 6
done

Phase 3: Verify Active Quarantine Enforcement

1. SOC Web Dashboard: Under BLOCKED & REPORTS, confirm 10.77.0.2 is listed with reason: Auto-blocked: AEGIS CLIENT LIVE SCAN DETECTED (3 alerts).
2. Aegis Sensor VM: Verify the kernel set contains the quarantined IP:

sudo nft list set inet aegis_filter blocked_clients

Output shows: elements = { 10.77.0.2 expires ... }
3. Aegis Client VM: Confirm traffic is blocked:

ping -c 2 -W 1 10.77.0.1

Output shows: 100% packet loss.

Phase 4: Admin Unblock & Remediation

1. In the SOC Dashboard under BLOCKED & REPORTS, click Unblock next to 10.77.0.2.
2. On Sensor VM, run sudo nft list set inet aegis_filter blocked_clients to confirm the element is cleared.
3. On Client VM, run ping -c 2 -W 1 10.77.0.1 to confirm connectivity is restored (0% packet loss).
